Telegram File Code Bot

上传一组文件
换一串取件码

页面支持一次上传多个文件，生成一个共享取件码。任何人把这个码发给你的机器人， 机器人就会把这组文件逐个发回去。有效期既支持临时，也支持永久。

一码多文件同一组图片、视频、文件会被归到同一个取件码里，分享和管理更省事。
临时或永久有效期输入 `30m`、`12h`、`7d`、`4w` 或 `forever`，按需控制生命周期。
机器人取件上传后会返回取件码和深链，直接贴给别人即可使用。
本地托管网页上传的文件由服务端保存，Telegram 上传的文件继续走 `file_id` 复用。
